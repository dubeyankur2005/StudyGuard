# 🚀 StudyGuard

> **A Full-Stack Productivity Platform that helps students stay focused while learning on YouTube.**

StudyGuard automatically tracks YouTube watch history, categorizes videos into **Study** and **Entertainment**, provides detailed analytics, and will soon include **Study Mode** to eliminate distractions while learning.

# 🚀 Getting Started

## Clone Repository

```bash
git clone https://github.com/your-username/StudyGuard.git
```

```bash
cd StudyGuard
```

---

## Backend Setup

```bash
cd backend
```

Install dependencies

```bash
npm install
```

Run server

```bash
npm run dev
```

---

## Frontend Setup

```bash
cd frontend
```

Install dependencies

```bash
npm install
```

Run application

```bash
npm run dev
```

---

## Chrome Extension

1. Open Chrome

2. Go to

```
chrome://extensions
```

3. Enable

```
Developer Mode
```

4. Click

```
Load Unpacked
```

5. Select

```
extension/
```
